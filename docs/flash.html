⛵ NauticPinnace

Flash the NauticPinnace firmware straight from the browser — no toolchain needed.

Requirements: Chrome or Edge (WebSerial), a Waveshare ESP32-S3-Touch-LCD-4 Rev 4 connected via USB-C. Flashing erases the on-device configuration. Read the safety notes in the README first — this is uncertified DIY firmware, use at your own risk.

1. Plug in the display via USB-C.
2. Click, pick the USB Serial Device port, wait about a minute.

If no port shows up: a board in a crashed state may need a manual bootloader entry — hold BOOT, tap RESET, release BOOT (buttons on the left edge).

After flashing, the display boots in English, asks for your language and shows a demo of all screens. Full setup instructions are in the README.
