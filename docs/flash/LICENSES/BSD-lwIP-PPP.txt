lwIP PPP - licence notices
==========================

These are the licence notices of the lwIP PPP files that the 7B and 5B
firmware images link (Arduino-ESP32 3.3.11 / ESP-IDF 5.5.5). The 4-inch image
(Arduino-ESP32 2.0.17 / ESP-IDF 4.4.7) links no PPP code.

Why PPP code is in the image although the firmware never opens a PPP link:
the ESP-IDF libraries that the 7B / 5B build compiles from ESP-IDF 5.5.5 are
configured with
CONFIG_LWIP_PPP_SUPPORT=y (with PAP and Van Jacobson header compression), and
lwIP's initialisation (lwip_init() in init.c) then calls ppp_init(), which
pulls the files below into the image.

The 7B and 5B images of release 1.2.0 (the v1.2.0 release package, and
docs/flash/7b and docs/flash/5b at tag v1.2.0) contain the same PPP files
under the same terms; these notices apply to them as well.

Linked files (lwIP as shipped with ESP-IDF 5.5.5,
components/lwip/lwip/src/netif/ppp/):

    auth.c  fsm.c  ipcp.c  lcp.c  magic.c  ppp.c  pppos.c  upap.c  vj.c

Below, each licence notice is reproduced as it appears in those files, with
only the comment markers removed. A notice that several files carry in the
same wording is given once, with the list of files it covers.
