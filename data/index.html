🔌 NMEA 2000 / CAN-Bus

Das Board hat einen eingebauten CAN-Transceiver (TJA1051) an der Schraubklemme (CANH/CANL).
Verändere diese Pins nur, wenn du eine andere Hardware-Revision nutzt.

Im Nur-mithören-Modus sendet das Display nichts auf den Bus — kein Address-Claim, kein Heartbeat, keine Fusion-Steuerung. Für fremde Boote oder Werkstatttermine.

⛵ Polardaten

Ziel-Bootsgeschwindigkeit (kn) je Windwinkel TWA (Zeilen, °) und Windgeschwindigkeit TWS (Spalten, kn). Wird auf dem Speed-&-Polar-Screen (Wert „Polar kn" / „Perf %") und im Wind-Performance-Balken verwendet. Zwischenwerte werden bilinear interpoliert.

Erste Zeile: twa,<TWS-Werte…> — jede weitere Zeile: <TWA>,<Geschwindigkeiten…>

🖼️ Boot-Logo

Eigenes Logo für den Bootscreen. Das Bild wird im Hintergrund der Spinner-Animation angezeigt.
Format: RGB565 .bin mit 4-Byte-Header (Breite + Höhe je uint16 LE).
Konvertierung: tools/logo_convert.py oder Online-Tool verwenden.
Empfohlene Größe: 160 × 160 px (max. 200 × 200 px).

🐍 Logo konvertieren (Python)

Speichere das Skript als logo_convert.py und führe es aus: 

pip install Pillow

python logo_convert.py logo.png logo.bin --size 160

Das Skript liegt unter tools/logo_convert.py im Projektverzeichnis.
